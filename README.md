# แผนที่เดินป่าออฟไลน์ (ต้นแบบเวอร์ชัน 0.1)

แอพมือถือ Android และ iPhone สำหรับดาวน์โหลดแผนที่ไว้ใช้ตอนไม่มีสัญญาณ

## ฟีเจอร์ในเวอร์ชันนี้
- เลื่อน/ซูมแผนที่ไปยังพื้นที่ที่จะเดินป่า แล้วกด **ดาวน์โหลดพื้นที่ที่เห็นบนจอ**
- แสดงตำแหน่งตัวเองด้วย GPS (ใช้ได้แม้ไม่มีอินเทอร์เน็ต) กดปุ่ม ◎ เพื่อตามตำแหน่ง
- รายการแผนที่ที่ดาวน์โหลดไว้ ดูขนาด กดเพื่อไปยังพื้นที่นั้น หรือลบทิ้ง
- ระดับซูมที่เก็บ: 10–15 (เห็นทางเดินและรายละเอียดชัดเจน)
- จำกัดขนาดพื้นที่ต่อครั้ง (ประมาณ 20,000 ไทล์) ถ้าใหญ่เกินจะแจ้งให้ซูมเข้า

- **ภูมิประเทศ:** เงาเขา (hillshade) แสดงสันเขา/หุบเขา, ทางเดินเท้าเป็นเส้นประสีส้ม, ป่า/น้ำ, ยอดเขาพร้อมความสูงเป็นเมตร
- แสดงความสูงจาก GPS ตรงมุมบนจอ
- **เส้นชั้นความสูง:** โค้ดรองรับแล้ว แต่ปิดอยู่ ต้องใส่ URL แหล่งข้อมูลใน `trailStyle.ts` (ค่า `CONTOUR_TILES_URL`)

- **บันทึกการเดินทาง:** กดปุ่ม ● ที่มุมล่างเพื่อเริ่ม กด ■ เพื่อหยุด แอพเก็บจุด GPS ลงไฟล์ในเครื่อง (ทำงานต่อได้แม้ล็อคหน้าจอหรือสลับแอพ ต้องอนุญาตตำแหน่ง "ตลอดเวลา") ดูเส้นบนแผนที่ และส่งออกเป็นไฟล์ GPX ได้ที่ "การเดินทางที่บันทึกไว้" (โค้ดอยู่ใน `tracker.ts`)
- **เว็บแอพ (`docs/`):** มีปุ่ม ● บันทึก (`docs/rec.js`) และ ☻ ทีม (`docs/team.js`) ใช้ผ่าน Safari ได้ แต่ iPhone ไม่ให้เว็บทำงานเบื้องหลัง ต้องเปิดจอและแอพค้างไว้
- **ทีมเดินป่า (แอพมือถือ):** ปุ่ม "ทีมเดินป่า" หัวหน้าสร้างทีมพร้อมเลือกเส้นทางที่บันทึกไว้ ได้รหัส 6 ตัวไปแจกเพื่อน (สูงสุด 10 เครื่อง) เพื่อนใส่รหัส + ชื่อไม่เกิน 16 ตัวอักษร + เลือกสี (10 สีไม่ซ้ำ) แล้วเห็นเส้นทางเดียวกันและตำแหน่งของกันและกันบนแผนที่ ส่งตำแหน่งต่อเนื่องแม้ล็อคจอ ต้องมีสัญญาณมือถือ/อินเทอร์เน็ตและต้องโฮสต์เซิร์ฟเวอร์ใน `server/` เอง (ดู `server/README.md`)

ยังไม่มี (เก็บไว้ทำเวอร์ชันถัดไป): วาด/แก้ไขเส้นทาง ปักหมุด นำเข้า-ส่งออก GPX

## วิธีรันบนเครื่องคุณ
ต้องมีคอมพิวเตอร์ที่ลง Node.js แล้ว

1. `npm install`
2. Android: ต่อมือถือแล้วรัน `npx expo run:android` (ต้องลง Android Studio)
3. iPhone: ต้องใช้เครื่อง Mac ที่ลง Xcode แล้วรัน `npx expo run:ios`

**หมายเหตุสำคัญ:** แอพนี้ใช้ส่วนเสริมของระบบ (native) จึงเปิดด้วยแอพ Expo Go **ไม่ได้** ต้อง build เป็นแอพของตัวเอง (หรือใช้ EAS Build ของ Expo สร้างไฟล์ติดตั้งบนคลาวด์)

## วิธีติดตั้งลงมือถือ Android แบบง่าย (ไม่ต้องลง Android Studio)
1. ลง Node.js (รุ่น LTS) จาก nodejs.org และสมัครบัญชี Expo ฟรีที่ expo.dev
2. แตกไฟล์ซิป เปิด Terminal ในโฟลเดอร์ แล้วรัน `npm install`
3. `npm install -g eas-cli` แล้ว `eas login`
4. `eas build --platform android --profile preview` (ตอบ Yes ถ้าถามให้สร้างโปรเจ็กต์/คีย์)
5. รอประมาณ 15-30 นาที จะได้ลิงก์ดาวน์โหลดไฟล์ .apk เปิดลิงก์บนมือถือ ติดตั้ง และอนุญาต "ติดตั้งแอพจากแหล่งที่ไม่รู้จัก"

## วิธีติดตั้งลง iPhone แบบไม่มี Mac และไม่เสียเงิน (ลองได้ แต่ยังไม่ได้ทดสอบ)
แอพจะหมดอายุทุก 7 วัน ต้องติดตั้งใหม่ทุกสัปดาห์

**ส่วนที่ 1: สร้างไฟล์ .ipa บน GitHub (ฟรี)**
1. สมัครบัญชี github.com แล้วสร้าง Repository ใหม่ แบบ **Public** (ใช้โควตาฟรีมากกว่า)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป **รวมโฟลเดอร์ซ่อน `.github`** (ถ้าลากไฟล์บนเว็บไม่ติด ให้ใช้ GitHub Desktop)
3. เปิดแท็บ **Actions** > เลือก "Build iOS (unsigned ipa)" > กด **Run workflow**
4. รอประมาณ 20-40 นาที เมื่อขึ้นเครื่องหมายถูกสีเขียว เปิดงานนั้น เลื่อนลงล่างสุด ดาวน์โหลด **TrailMap-ipa** (ได้ไฟล์ซิป ข้างในมี TrailMap.ipa)
5. ถ้าขึ้นสีแดง ให้คัดลอกข้อความ error ท้ายสุดมาให้ผมแก้

**ส่วนที่ 2: ติดตั้งด้วย Sideloadly (บน Windows)**
1. ลง iTunes และ iCloud จากเว็บไซต์ Apple (ไม่ใช่จาก Microsoft Store) และลง Sideloadly จาก sideloadly.io
2. ต่อ iPhone เข้าคอมพิวเตอร์ด้วยสาย กด "เชื่อถือคอมพิวเตอร์เครื่องนี้"
3. เปิด Sideloadly ลากไฟล์ TrailMap.ipa ใส่ ใส่ Apple ID ของคุณ แล้วกด Start
4. บน iPhone เปิด ตั้งค่า > ความเป็นส่วนตัวและความปลอดภัย > เปิด **Developer Mode** แล้วรีสตาร์ท
5. ตั้งค่า > ทั่วไป > การจัดการ VPN และอุปกรณ์ > เลือก Apple ID ของคุณ > ไว้วางใจ
6. เปิดแอพ TrailMap ได้เลย

## ข้อควรรู้เรื่องแหล่งแผนที่
- ใช้สไตล์ฟรีจาก OpenFreeMap (ข้อมูล OpenStreetMap) ไม่ต้องใช้คีย์
- ข้อมูลความสูงมาจาก Terrain Tiles (AWS Open Data) ละเอียดประมาณ 40 เมตร
- สไตล์แผนที่ถูกเขียนเป็นไฟล์ในเครื่องตอนเปิดแอพ (ดู `trailStyle.ts`) ยังไม่ได้ทดสอบบนเครื่องจริง ถ้าดาวน์โหลดแล้วขึ้น error ให้แจ้งข้อความมา
- ถ้าจะปล่อยให้คนทั่วไปใช้ ควรย้ายไปใช้ผู้ให้บริการแผนที่แบบเสียเงินหรือโฮสต์ไทล์เอง เพื่อความเสถียร
- ห้ามดาวน์โหลดไทล์จำนวนมากจากเซิร์ฟเวอร์ tile.openstreetmap.org โดยตรง (ผิดนโยบายการใช้งาน)

## ไฟล์สำคัญ
- `App.tsx` โค้ดหน้าจอทั้งหมด
- `team.ts`, `TeamPanel.tsx` ฟีเจอร์ทีม (ฝั่งแอพ) และ `server/` เซิร์ฟเวอร์ทีม
- `tracker.ts` บันทึกการเดินทางเบื้องหลัง เก็บไฟล์ และส่งออก GPX
- `trailStyle.ts` สไตล์แผนที่เดินป่า (เงาเขา ยอดเขา ทางเดิน)
- `app.json` การตั้งค่าแอพและสิทธิ์ตำแหน่ง
