# แผนที่เดินป่าออฟไลน์ (ต้นแบบเวอร์ชัน 0.1)

แอพมือถือ Android และ iPhone สำหรับดาวน์โหลดแผนที่ไว้ใช้ตอนไม่มีสัญญาณ

## ฟีเจอร์ในเวอร์ชันนี้
- เลื่อน/ซูมแผนที่ไปยังพื้นที่ที่จะเดินป่า แล้วกด **ดาวน์โหลดพื้นที่ที่เห็นบนจอ**
- แสดงตำแหน่งตัวเองด้วย GPS (ใช้ได้แม้ไม่มีอินเทอร์เน็ต) กดปุ่ม ◎ เพื่อตามตำแหน่ง
- รายการแผนที่ที่ดาวน์โหลดไว้ ดูขนาด กดเพื่อไปยังพื้นที่นั้น หรือลบทิ้ง
- ระดับซูมที่เก็บ: 10–15 (เห็นทางเดินและรายละเอียดชัดเจน)
- จำกัดขนาดพื้นที่ต่อครั้ง (ประมาณ 20,000 ไทล์) ถ้าใหญ่เกินจะแจ้งให้ซูมเข้า

- **ภูมิประเทศ:** เงาเขา (hillshade) แสดงสันเขา/หุบเขา, ทางเดินเท้าเป็นเส้นประสีส้ม, ป่า/น้ำ, ยอดเขาพร้อมความสูงเป็นเมตร
- แสดงความสูงจาก GPS ตรงมุมบนจอ
- **เส้นชั้นความสูง:** โค้ดรองรับแล้ว แต่ปิดอยู่ ต้องใส่ URL แหล่งข้อมูลใน `trailStyle.ts` (ค่า `CONTOUR_TILES_URL`)

- **บันทึกการเดินทาง:** กดปุ่ม ● ที่มุมล่างเพื่อเริ่ม กด ■ เพื่อหยุด แอพเก็บจุด GPS ลงไฟล์ในเครื่อง (ทำงานต่อได้แม้ล็อคหน้าจอหรือสลับแอพ ต้องอนุญาตตำแหน่ง "ตลอดเวลา") ดูเส้นบนแผนที่ และส่งออกเป็นไฟล์ GPX ได้ที่ "การเดินทางที่บันทึกไว้" (โค้ดอยู่ใน `tracker.ts`)
- **เว็บแอพ (`docs/`):** มีปุ่ม ● บันทึก (`docs/rec.js`) และ ☻ ทีม (`docs/team.js`) ใช้ผ่าน Safari ได้ แต่ iPhone ไม่ให้เว็บทำงานเบื้องหลัง ต้องเปิดจอและแอพค้างไว้
- **ทีมเดินป่า (แอพมือถือ):** ปุ่ม "ทีมเดินป่า" หัวหน้าสร้างทีมพร้อมเลือกเส้นทางที่บันทึกไว้ ได้รหัส 6 ตัวไปแจกเพื่อน (สูงสุด 10 เครื่อง) เพื่อนใส่รหัส + ชื่อไม่เกิน 16 ตัวอักษร + เลือกสี (10 สีไม่ซ้ำ) แล้วเห็นเส้นทางเดียวกันและตำแหน่งของกันและกันบนแผนที่ ส่งตำแหน่งต่อเนื่องแม้ล็อคจอ ต้องมีสัญญาณมือถือ/อินเทอร์เน็ตและต้องโฮสต์เซิร์ฟเวอร์ใน `server/` เอง (ดู `server/README.md`)

ยังไม่มี (เก็บไว้ทำเวอร์ชันถัดไป): วาด/แก้ไขเส้นทาง ปักหมุด นำเข้า-ส่งออก GPX

## วิธีรันบนเครื่องคุณ
ต้องมีคอมพิวเตอร์ที่ลง Node.js แล้ว

1. `npm install`
2. Android: ต่อมือถือแล้วรัน `npx expo run:android` (ต้องลง Android Studio)
3. iPhone: ต้องใช้เครื่อง Mac ที่ลง Xcode แล้วรัน `npx expo run:ios`

**หมายเหตุสำคัญ:** แอพนี้ใช้ส่วนเสริมของระบบ (native) จึงเปิดด้วยแอพ Expo Go **ไม่ได้** ต้อง build เป็นแอพของตัวเอง (หรือใช้ EAS Build ของ Expo สร้างไฟล์ติดตั้งบนคลาวด์)

## วิธีติดตั้งลงมือถือ Android แบบง่าย (ไม่ต้องลง Android Studio)
1. ลง Node.js (รุ่น LTS) จาก nodejs.org และสมัครบัญชี Expo ฟรีที่ expo.dev
2. แตกไฟล์ซิป เปิด Terminal ในโฟลเดอร์ แล้วรัน `npm install`
3. `npm install -g eas-cli` แล้ว `eas login`
4. `eas build --platform android --profile preview` (ตอบ Yes ถ้าถามให้สร้างโปรเจ็กต์/คีย์)
5. รอประมาณ 15-30 นาที จะได้ลิงก์ดาวน์โหลดไฟล์ .apk เปิดลิงก์บนมือถือ ติดตั้ง และอนุญาต "ติดตั้งแอพจากแหล่งที่ไม่รู้จัก"

## วิธีติดตั้งลง iPhone แบบไม่มี Mac และไม่เสียเงิน (ลองได้ แต่ยังไม่ได้ทดสอบ)
แอพจะหมดอายุทุก 7 วัน ต้องติดตั้งใหม่ทุกสัปดาห์

**ส่วนที่ 1: สร้างไฟล์ .ipa บน GitHub (ฟรี)**
1. สมัครบัญชี github.com แล้วสร้าง Repository ใหม่ แบบ **Public** (ใช้โควตาฟรีมากกว่า)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป **รวมโฟลเดอร์ซ่อน `.github`** (ถ้าลากไฟล์บนเว็บไม่ติด ให้ใช้ GitHub Desktop)
3. เปิดแท็บ **Actions** > เลือก "Build iOS (unsigned ipa)" > กด **Run workflow**
4. รอประมาณ 20-40 นาที เมื่อขึ้นเครื่องหมายถูกสีเขียว เปิดงานนั้น เลื่อนลงล่างสุด ดาวน์โหลด **TrailMap-ipa** (ได้ไฟล์ซิป ข้างในมี TrailMap.ipa)
5. ถ้าขึ้นสีแดง ให้คัดลอกข้อความ error ท้ายสุดมาให้ผมแก้

**ส่วนที่ 2: ติดตั้งด้วย Sideloadly (บน Windows)**
1. ลง iTunes และ iCloud จากเว็บไซต์ Apple (ไม่ใช่จาก Microsoft Store) และลง Sideloadly จาก sideloadly.io
2. ต่อ iPhone เข้าคอมพิวเตอร์ด้วยสาย กด "เชื่อถือคอมพิวเตอร์เครื่องนี้"
3. เปิด Sideloadly ลากไฟล์ TrailMap.ipa ใส่ ใส่ Apple ID ของคุณ แล้วกด Start
4. บน iPhone เปิด ตั้งค่า > ความเป็นส่วนตัวและความปลอดภัย > เปิด **Developer Mode** แล้วรีสตาร์ท
5. ตั้งค่า > ทั่วไป > การจัดการ VPN และอุปกรณ์ > เลือก Apple ID ของคุณ > ไว้วางใจ
6. เปิดแอพ TrailMap ได้เลย

## ช่องค้นหา (🔍 มุมบนซ้าย)
- **พิกัดทุกรูปแบบ:** MGRS, UTM, องศา ลิปดา ฟิลิปดา, องศา ลิปดาทศนิยม, องศาทศนิยม พิมพ์แล้วไปที่จุดนั้นทันที แสดงพิกัดเดียวกันครบทุกรูปแบบ และปักหมุดได้
- **ชื่อสถานที่:** หาในแผนที่ที่โหลดอยู่บนจอก่อน (ออฟไลน์ได้ ได้เฉพาะชื่อที่อยู่ในแผนที่ที่โหลดไว้) แล้วถามบริการ Nominatim ของ OpenStreetMap เพิ่ม (ต้องมีเน็ต ชื่อที่พิมพ์ถูกส่งไปยังบริการนี้)
- **ลักษณะภูมิประเทศ:** ยอดเขา สันเขา คอเขา หุบเขา ร่องน้ำ หน้าผา/ลาดชันมาก ที่ต่ำบนภูเขา (เส้นคุ้งกระทะ) วิเคราะห์ในเครื่องจากข้อมูลความสูง ละเอียดราว 30-40 ม. รอบกลางจอกว้างราว 28 กม. (`docs/terrain.js`) เป็นค่าประมาณ ไม่ใช่การสำรวจ ต้องตรวจกับสภาพจริง
- **ยอดเขาและที่ต่ำ (เปิดพร้อมเส้นชั้นความสูง ซูม 12 ขึ้นไป):** ทุกยอดที่มีเส้นชั้นวงปิดล้อมรอบจะมีเครื่องหมาย X พร้อมความสูง (เมตร) ส่วนที่ต่ำ/แอ่งปิดจะวาดเส้นคุ้งกระทะมีขีดสั้นชี้เข้าหาที่ต่ำแบบในตำรา คำนวณในเครื่องจากข้อมูลความสูงชุดเดียวกับเส้นชั้น จึงเป็นค่าประมาณ (ต่างจากหมุดหมายทางการได้หลายเมตร) ยอดเขาจาก OpenStreetMap จะเหลือแค่ชื่อ
- **ชนิดเส้นชั้นความสูง:** หลัก (100 ม.) รอง (20 ม.) แทรก (10 ม.) โดยประมาณ (เส้นประ) คุ้งกระทะ (แอ่งปิด) เส้นทุกเส้นสร้างจากข้อมูลความสูง จึงเป็นค่าโดยประมาณทั้งหมด ไม่ใช่เส้นสำรวจแบบแผนที่ทหาร

## วาดตึกและสถานโบราณเอง (ปุ่ม 🏛 สร้างตึก)
- วาดสิ่งปลูกสร้างลงแผนที่แล้วยกเป็น 3 มิติ: บ้าน ตึก/อาคาร (ตั้งจำนวนชั้น) ตึกแถว โบสถ์/วิหาร (หลังคาซ้อน) เจดีย์/สถูป ปราสาท/ปรางค์โบราณ หอคอย ศาลา ซากโบราณสถาน และกำแพง/คูเมือง (วาดเป็นเส้น)
- เพิ่มชนิด (กลุ่มทหาร/ความปลอดภัย เครื่องบิน ยานพาหนะ): ค่าย/อาคารกองบังคับการ ป้อมรักษาการณ์ ประตู(2 จุด) พื้นที่ต้องห้าม(สีแดง) เสาวิทยุ เส้นสลิง(ตั้งความสูงจากพื้น) โรงเก็บเครื่องบิน รันเวย์ เครื่องบินลำเล็ก/ขนส่ง เฮลิคอปเตอร์ รถยนต์ รถบรรทุก/รถทหาร รถถัง · และกลุ่มทั่วไป: โรงจอดรถ หอประชุมแบบเปิด/ปิด ห้องน้ำ · รูปจำลองแตะจุดเดียว ปรับทิศหันและขนาดได้
- ปุ่มเปิด/ปิดชื่อสิ่งก่อสร้างบนแผนที่ (รวม) และเลือกซ่อนชื่อรายหลังได้
- วิธีวาด: สี่เหลี่ยม (แตะ 3 จุด) · หลายเหลี่ยม (แตะทีละมุม แล้วกด ✓ เสร็จ) · เส้น · มีปุ่มย้อน/ยกเลิก · เสร็จแล้วตั้งชื่อ ชั้น/ความสูง สี ย้ายตำแหน่ง หรือลบได้ (แตะอาคารบนแผนที่เพื่อแก้)
- เก็บในเครื่องและอยู่ในงาน (Project) ที่ใช้อยู่ ติ๊กแสดง/ซ่อน ส่งออก/นำเข้าพร้อมงานได้ · ใช้ทับภาพดาวเทียมและมุมมอง 3D ได้ · รูปทรงเป็นแบบจำลองหยาบ ไม่ใช่แบบสถาปัตยกรรมจริง
## อาคาร 3 มิติ (ชั้นแผนที่ → "อาคาร 3 มิติ")
- ยกรูปอาคารจาก OpenStreetMap (ข้อมูลที่อยู่ในไทล์เวกเตอร์ชุดเดียวกับแผนที่เดินป่า) ขึ้นเป็นทรง 3 มิติ ซูม 14 ขึ้นไป ทับบนแผนที่เดินป่าหรือภาพดาวเทียมได้ ใช้ร่วมกับมุมมอง 3D ได้ สีเข้มขึ้นตามความสูง
- ความสูงมาจากข้อมูลที่ผู้ใช้ OSM บันทึกไว้ (render_height) ถ้าอาคารไม่มีข้อมูลความสูงจะสมมุติ 6 ม. · อาคารที่ยังไม่มีใครวาดใน OSM จะไม่ขึ้น (แอพไม่ได้สร้างตึกจากภาพดาวเทียมเอง) · ใช้ออฟไลน์ได้ในพื้นที่ที่ดาวน์โหลดไว้

## วัดมุม: จุด A–H และลากเส้น
- ตั้งจำนวนจุดได้ 2–8 (A–H) แตะวางต่อกันตามลำดับ ลากหมุดย้ายได้
- ลากเส้นจากจุดหนึ่งไปอีกจุด หรือลากเลยจุดไปยาว 5 / 10 / 15 / 20 กม. แสดงมุมกริด มิล และระยะของทุกเส้น
- ตั้งได้ว่าจุดและเส้นอยู่บนสุด หรืออยู่ใต้แผ่นวัดมุม/เข็มทิศ และการ์ดค่ามุมอยู่ด้านบนหรือด้านล่างจอ

## เข็มทิศเล็ง (ปุ่ม 🧭 เข็มทิศ)
- ถือเครื่องตั้งขึ้น เล็งผ่านช่องเล็งและลวดเล็งแบบเข็มทิศเลนเซติก ภาพกล้องหลังเป็นพื้นหลัง อ่านหน้าปัดผ่านเลนส์ (องศาสีแดง มิลสีดำ) ใช้เข็มทิศของเครื่อง ออฟไลน์ได้
- แสดงทิศเป็นองศา มิล และชื่อทิศ 16 ทิศ · เลือกแม่เหล็ก/เหนือจริง · โหมดกลางคืน
- ปุ่ม: ล็อคทิศ · เป้าหมาย (บอกหันซ้าย/ขวา) · ฝึก (สุ่มมุมให้เล็ง ซ่อนค่าแล้วตรวจความคลาด) · บันทึก (เก็บมุมพร้อมเวลา และวาดเส้นเล็ง 5 กม. จากตำแหน่ง GPS บนแผนที่)

## มุมมอง 3D (ปุ่ม ⛰ 3D)
- **🧭 เล็ง (เข็มทิศเลนเซติก ในมุมมอง 3D):** เส้นเล็งกลางจอ + หน้าปัดที่เห็นผ่านเลนส์ (องศาสีแดง มิลสีดำ) หมุนตามทิศที่หัน อ่านมุมแม่เหล็กตามมุมเบี่ยงเบนที่ตั้งไว้ · กด "📌 บันทึกมุมเล็ง" จะวาดเส้นจากจุดยืนตามมุมนั้น ยาว 5–20 กม. บนแผนที่ (ใช้หาตำแหน่งแบบสกัดกลับได้)
- **มุมมองพื้นดิน:** ยืนที่กลางจอหรือตำแหน่ง GPS ของคุณ ความสูงสายตาปรับได้ (1–400 ม.) ลากนิ้วเพื่อหันหน้าและก้มเงย บีบนิ้วเพื่อซูม ปุ่มก้าว/ถอยครั้งละ 100 ม. มีท้องฟ้าและหมอกไกล
- **มุมมองเอียง 3D:** มองจากด้านบนแบบเอียง หมุนและเอียงด้วยสองนิ้ว
- ภูมิประเทศยกจากข้อมูลความสูงละเอียดราว 30-40 ม. ใช้ได้ออฟไลน์เมื่อดาวน์โหลดพื้นที่ไว้ เห็นรูปทรงเขา สันเขา หุบเขา แต่ไม่มีต้นไม้ อาคาร หรือหินก้อนเล็ก ภาพดาวเทียมเป็นพื้นหลังจะสมจริงที่สุด (ต้องดาวน์โหลดดาวเทียมของพื้นที่นั้นไว้)
- เงยขึ้นเหนือแนวนอนไม่ได้ (ข้อจำกัดของไลบรารีแผนที่) จึงเห็นฟ้าได้เฉพาะส่วนที่อยู่เหนือขอบฟ้าในมุมมองกล้อง ปรับ "มุมมองกล้อง" ให้กว้างขึ้นเพื่อเห็นฟ้ามากขึ้น

## พิมพ์แผนที่เดินป่า (เมนูพิมพ์ → พื้นหลัง "แผนที่เดินป่า")
- พิมพ์แผนที่ชุดเดียวกับในแอพ: ป่า น้ำ ถนน ทางเดิน ชื่อสถานที่ เงาเขา (อ่อนลงสำหรับกระดาษ) เส้นชั้นความสูง (เส้นหลักหนา มีตัวเลข) ยอดเขา X + ความสูง และเส้นคุ้งกระทะมีขีด จัดเข้ากริด UTM ตามมาตราส่วนที่เลือก
- ตัวหนังสือบนแผนที่สูงราว 2 มม. ทุกความละเอียด · กระดาษใหญ่ (A2 ขึ้นไป) วาดเป็นช่องๆ ใช้เวลานานขึ้น
- ต้องออนไลน์ หรือดาวน์โหลดพื้นที่นั้นไว้ก่อน

## สร้างแผนที่สมมุติเพื่อการสอน (เมนูพิมพ์ → พื้นหลัง "แผนที่สมมุติ")
- สร้างพื้นที่สมมุติจากเลข seed (เลขเดิม = แผนที่เดิม) มี 16 แบบ: ภูเขา เนินเขา ที่ราบ ที่ราบสูง เทือกเขาซ้อน เนินเขาถี่ เขาหินปูนโดด ภูยอดตัด ยอดเขาเดี่ยว และแบบคล้ายอุทยาน (ดอยอินทนนท์ เชียงดาว เขาใหญ่ ภูกระดึง ภูหินร่องกล้า แก่งกระจาน พังงา/เขาสก สามร้อยยอด ซึ่งเป็นการจำลองลักษณะ ไม่ใช่แผนที่จริง) ปรับต่างระดับได้ 40–500% ระดับฐาน และช่วงห่างเส้นชั้น (มาตรฐาน 20 ม. หลัก 100 ม.)
- ปุ่ม "ดูภาพ 3 มิติ" (หลังกดสร้าง): ภาพก้อนภูมิประเทศของพื้นที่เดียวกับแผนที่ ลากนิ้วหมุน/ก้มเงย ถ่างสองนิ้ว (หรือปุ่ม +/−) ซูมได้ถึง 10 เท่า แตะจุดบนภาพเพื่อปักหมุดแล้วหมุน/ซูมรอบจุดนั้น ปุ่ม "ดูทั้งแผ่น" กลับมุมเดิม ปรับขยายความสูง 1–4 เท่า เปิด/ปิดป้ายลักษณะภูมิประเทศและเส้นชั้นความสูงบนพื้น บันทึกเป็น PNG (2600×1650) ใส่สไลด์ได้
- เลือกสีที่พิมพ์ได้: สี / ขาว-ดำมีเฉดเทา / ขาว-ดำล้วน (เส้นดำพื้นขาว เหมาะเครื่องพิมพ์ขาว-ดำและถ่ายเอกสาร)
- เลือกรายละเอียดทีละอย่าง: เส้นชั้นหลัก/รอง/แทรก/โดยประมาณ/คุ้งกระทะ ยอดเขา สันเขา คอเขา หุบเขา หน้าผา ร่องน้ำ แม่น้ำ ห้วย หนอง ป่า ไร่ นา สวน หมู่บ้าน โรงเรียน วัด สถานพยาบาล ที่ทำการ ตลาด สุสาน ถนน ทางเกวียน ทางเดิน สะพาน สายไฟ ชื่อและเลขกำกับ มีปุ่มชุดสำเร็จ (ทั้งหมด/เฉพาะเส้นชั้น/เฉพาะลักษณะเขา/ไม่ใส่)
- กระดาษ A6–A0, B5, B4, Letter หรือกำหนดเองเป็นมม. มาตราส่วนเลือกได้หรือพิมพ์ 1:N เอง ถ้ากระดาษใหญ่มากจะลด dpi อัตโนมัติ (จำกัดพื้นที่ภาพของ iOS) และแจ้งบนหน้าจอ
- รายละเอียดใต้แผนที่เลือกใส่หรือไม่ใส่ได้: สเกลบาร์ ทิศเหนือ ตาราง มุมกระดาษ เครดิต ช่วงห่างเส้นชั้น คำอธิบายสัญลักษณ์ โจทย์คำถาม (พิมพ์เอง ใส่เลขอัตโนมัติ พร้อมเส้นตอบ) ช่องชื่อนักเรียน และหน้าเฉลย
- ปุ่มไฟล์: PDF แผนที่ / PDF เฉลย (พิกัดตามรูปแบบที่เลือก + ความสูง) / PDF รวม
- ข้อจำกัด: เป็นภูมิประเทศสุ่มจำลอง ไม่ใช่ของจริง ยังไม่ได้ทดสอบบน iPhone จริงหรือพิมพ์ลงกระดาษจริง

## ข้อควรรู้เรื่องแหล่งแผนที่
- ใช้สไตล์ฟรีจาก OpenFreeMap (ข้อมูล OpenStreetMap) ไม่ต้องใช้คีย์
- ข้อมูลความสูงมาจาก Terrain Tiles (AWS Open Data) ละเอียดประมาณ 40 เมตร
- สไตล์แผนที่ถูกเขียนเป็นไฟล์ในเครื่องตอนเปิดแอพ (ดู `trailStyle.ts`) ยังไม่ได้ทดสอบบนเครื่องจริง ถ้าดาวน์โหลดแล้วขึ้น error ให้แจ้งข้อความมา
- ถ้าจะปล่อยให้คนทั่วไปใช้ ควรย้ายไปใช้ผู้ให้บริการแผนที่แบบเสียเงินหรือโฮสต์ไทล์เอง เพื่อความเสถียร
- ห้ามดาวน์โหลดไทล์จำนวนมากจากเซิร์ฟเวอร์ tile.openstreetmap.org โดยตรง (ผิดนโยบายการใช้งาน)
