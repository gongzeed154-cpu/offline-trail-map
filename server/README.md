# เซิร์ฟเวอร์ทีมเดินป่า

เซิร์ฟเวอร์เล็กๆ (Node.js + WebSocket) ที่ส่งต่อตำแหน่งและเส้นทางระหว่างเครื่องในทีมเดียวกัน
เก็บข้อมูลในหน่วยความจำเท่านั้น ไม่มีฐานข้อมูล รีสตาร์ทแล้วทีมจะหาย (ทีมที่ไม่มีใครออนไลน์เกิน 24 ชม. จะถูกลบเอง)

## กติกา
- ทีมละไม่เกิน **10 เครื่อง**, ชื่อไม่เกิน **16 ตัวอักษร**, **10 สีไม่ซ้ำกัน** ในทีมเดียวกัน
- หัวหน้าทีมสร้างทีมพร้อมเส้นทาง แล้วได้รหัส 6 ตัวไปแจกเพื่อน เฉพาะหัวหน้าเปลี่ยนเส้นทางหรือยุบทีมได้
- สัญญาณหลุดแล้วกลับมา เชื่อมต่อทีมเดิมได้เอง (ไม่เสียที่นั่ง)

## รัน
```
cd server
npm install
npm start          # พอร์ต 8080 (เปลี่ยนด้วย PORT=9000 npm start)
npm test           # ทดสอบโปรโตคอล
```
ตรวจว่าทำงาน: `curl http://localhost:8080/health` ต้องได้ `ok`

## ติดตั้งให้ใช้ได้จริง
แอพต้องเชื่อมผ่าน **wss://** (TLS) เท่านั้น เพราะ Android/iOS บล็อก ws:// ธรรมดา ทางที่ง่ายที่สุด:
1. เช่า VPS เล็กๆ หรือใช้บริการอย่าง Fly.io / Railway / Render (รองรับ Docker ได้เลย: `docker build -t trail-team server`)
2. ให้บริการนั้นออก HTTPS ให้ (หรือใช้ Caddy/nginx เป็นตัวหน้า แล้ว proxy ไปพอร์ต 8080 โดยเปิดการอัปเกรด WebSocket)
3. ในแอพ ใส่ที่อยู่เช่น `wss://team.example.com` ที่หน้า "ทีมเดินป่า"

## โปรโตคอล (JSON ต่อ 1 ข้อความ)
| ไคลเอนต์ → เซิร์ฟเวอร์ | ความหมาย |
|---|---|
| `{t:'create', name, color, route:[[lng,lat],...]}` | สร้างทีม (ต้องมีเส้นทาง ≥ 2 จุด ≤ 5000 จุด) |
| `{t:'join', code, name, color}` | เข้าทีมด้วยรหัส |
| `{t:'resume', code, id, token}` | เชื่อมต่อใหม่ |
| `{t:'pos', lat, lng, alt, acc, ts}` | ส่งตำแหน่ง (เซิร์ฟเวอร์รับไม่ถี่กว่า 1.5 วินาที) |
| `{t:'route', route}` | หัวหน้าเปลี่ยนเส้นทาง |
| `{t:'leave'}` / `{t:'disband'}` | ออกจากทีม / ยุบทีม (หัวหน้า) |

เซิร์ฟเวอร์ตอบ `joined`, `state`, `pos`, `presence`, `route`, `disbanded`, `error {code}`

## ข้อควรระวัง
- รหัสทีมคือกุญแจเดียว ใครรู้รหัสก็เข้าได้ (ถ้าทีมยังไม่เต็ม) อย่าโพสต์รหัสสาธารณะ
- ยังไม่มีบัญชีผู้ใช้/การจำกัดจำนวนทีมต่อ IP ถ้าเปิดสาธารณะควรใส่ rate limit ที่ proxy ด้านหน้า
