# ศึกอ่านแผนที่ — เกมแผนที่เรียลไทม์ (ห้องเรียน 80–100 คน, ~5 นาที)

นักเรียนสแกน QR → ใส่ชื่อ → ปักหมุดตอบบนแผนที่ให้ใกล้คำตอบที่สุด  
หน้าจอหน้าห้องแสดงเวลานับถอยหลัง จำนวนคนที่ตอบแล้ว และ **คะแนนรวมเป็น % แบบสด** ตลอดเกม

## วิธีใช้ (ครู)

1. คอมครูต้องมีอินเทอร์เน็ต และติดตั้ง `cloudflared` (มีแล้วบนเครื่องนี้) — **นักเรียนใช้เน็ตมือถือตัวเองได้ ไม่ต้องต่อ Wi-Fi เดียวกัน**
   เซิร์ฟเวอร์จะเปิดอุโมงค์ Cloudflare ให้เองและสร้าง QR จากลิงก์สาธารณะ (`https://xxxx.trycloudflare.com`) ลิงก์เปลี่ยนทุกครั้งที่รัน
2. เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน (ต้องมี Node.js 18+; ไม่ต้อง `npm install`)

   ```bash
   node server.js
   ```
   หรือดับเบิลคลิก `start-game.bat`  
   ครั้งแรก Windows อาจถามเรื่อง Firewall → กด **Allow / อนุญาต** (เครือข่ายส่วนตัว)
3. เปิด **http://localhost:3000/host** ในเบราว์เซอร์ แล้วฉายขึ้นโปรเจกเตอร์ (กด F11 เต็มจอ)
4. นักเรียนสแกน QR บนจอ → กรอกชื่อ/เลขที่ → รอ
5. กด **▶ เริ่มเกม** (หรือกด Space)

| ปุ่มลัดบนจอครู | ทำอะไร |
|---|---|
| Space | เริ่มเกม (ตอนอยู่หน้ารอ) |
| → | ข้ามไปเฉลย / ข้อถัดไป |
| ปุ่มเล็กมุมขวาล่าง | รีเซ็ตเกม (เก็บรายชื่อ) / ล้างรายชื่อ |

## รูปแบบเกม (14 ข้อ ≈ 8 นาที — ไม่เกิน 10 นาที)

| ชนิดข้อ | จำนวน | ตอบอย่างไร |
|---|---|---|
| หาสถานที่ | 2 | ปักหมุดบนแผนที่ |
| ภูมิประเทศ | 3 | ปักหมุด "จุดสูงที่สุด" บนแผนที่ที่ระบายสีตามความสูง + เงาภูเขา (จุดเฉลยคำนวณจากข้อมูลความสูงจริง) |
| พิกัด ° ′ ″ | 4 | 2 ข้อปักหมุดตามพิกัดที่โจทย์ให้ (มีเส้นกริดทุก 1 ลิปดาและป้ายพิกัด) + 2 ข้อกรอก องศา/ลิปดา/ฟิลิปดา ของหมุดที่เห็น |
| เข็มทิศ | 3 | ลากเข็มบนหน้าปัดให้ตรงมุมภาค (azimuth) / back azimuth / เลี้ยวซ้ายขวา |
| เข็มทิศประกอบแผนที่ | 2 | ดูจุด A→B บนแผนที่ แล้วตั้งมุมภาคบนหน้าปัด (คำนวณเฉลยจากพิกัดจริง) |

- เวลาแต่ละข้อตั้งแยกได้ (`seconds`) รวมเฉลยข้อละ 6 วินาที — ถ้าทุกคนตอบครบก่อนเวลา จะเฉลยทันที
- หมดเวลา → ระบบส่งคำตอบที่ตั้งไว้ให้อัตโนมัติ (ไม่ตอบเลย = 0%)

### จอหลัก (ฉาย 16:9) กับจอนักเรียน
- **จอหลัก** (`/host`): ล็อกสัดส่วน 16:9 (เวที 1920×1080 สเกลตามจอ มีแถบดำถ้าสัดส่วนไม่ตรง) แสดงโจทย์ เวลานับถอยหลัง คะแนนรวมสดเป็น % และเสียงทั้งหมด
- **มือถือนักเรียน**: เงียบ แสดงเฉพาะโจทย์ ช่องตอบ เวลานับถอยหลังของข้อนั้น และเฉลยคำตอบที่ถูก (ไม่มี % อันดับ หรือคะแนนรวม — ดูที่จอหลัก)

### ตัวละคร เสียง และบรรยากาศ
- นักเรียนเลือกไอคอน (สัตว์ / ทหาร / การ์ตูน / กีฬา) + สีกรอบ + ตั้งชื่อ หรือกด 🎲 สุ่มชื่อ — ชื่อซ้ำต่อเลขให้อัตโนมัติ
- หน้าจอครูตอนรอ: บัตรตัวละครเด้งเข้ามาทีละคน พร้อมเสียงและป้าย "🎉 … เข้าร่วมแล้ว!" **ดับเบิลคลิกบัตรเพื่อเชิญออก**
- เสียงทั้งหมดออกที่จอหลักเท่านั้น
- เพลงพื้นหลัง (ห้องรอ / ระหว่างเล่น / จบเกม) เอฟเฟกต์เสียง นับถอยหลัง และเพลงเร่งจังหวะ 5 วินาทีสุดท้าย — สังเคราะห์ด้วยโค้ด ไม่ต้องมีไฟล์เสียง
- **เสียงพูด AI** อ่านโจทย์ เฉลย และประกาศผู้ชนะ ใช้เสียงภาษาไทยของเบราว์เซอร์ — **ใช้ Microsoft Edge** จะมีเสียง Natural (ถ้าไม่พบเสียงไทยจะแสดงคำบรรยายบนจอแทน)
- เบราว์เซอร์บังคับให้คลิก/กดปุ่มก่อนจึงจะเปิดเสียงได้ — คลิกที่หน้าจอครูหนึ่งครั้งก่อนเริ่มเกม
- ปุ่มเล็กมุมขวาล่างจอครู: 🎵 เพลง · 🔊 เอฟเฟกต์ · 🗣️ เสียงพูด (ลัด M = เพลง, V = เสียงพูด)
- หน้าสรุป: โพเดียม 3 อันดับ + พลุกระดาษ

### การคิดคะแนน
คะแนนต่อข้อ = `100 × (1 − ระยะห่าง ÷ ระยะสูงสุด)` (ต่ำสุด 0) — ระยะห่างคำนวณด้วยสูตร Haversine  
ข้อเข็มทิศใช้ความคลาดเคลื่อนของมุมแทน: `100 × (1 − มุมคลาด ÷ maxDeg)` (ค่าเริ่มต้น 45°)  
**คะแนนรวม % = ค่าเฉลี่ยของทุกข้อที่เล่นไปแล้ว** (ข้อที่ยังไม่ตอบนับเป็น 0 ระหว่างข้อ จึงเห็นเปอร์เซ็นต์ขยับขึ้นสดตอนมีคนตอบ)

## แก้โจทย์

แก้ไฟล์ `questions.json` แล้วรีสตาร์ทเซิร์ฟเวอร์ ชนิดโจทย์ (`type`):

```json
{ "type": "pin",     "prompt": "…", "name": "ชื่อตอนเฉลย", "lat": 13.69, "lng": 100.75, "maxKm": 150, "labels": true }
{ "type": "pin",     "terrain": true, "frame": [w, s, e, n], "lat": …, "lng": …, "maxKm": 4 }              // ภูมิประเทศ ล็อกกรอบ
{ "type": "pin",     "grid": 1, "readout": "dms", "frame": [w, s, e, n], … }                              // ปักตามพิกัด ° ′ ″
{ "type": "dms",     "grid": 1, "frame": [w, s, e, n], "lat": …, "lng": …, "dmsText": "13°44′37″N …" }   // กรอกพิกัด
{ "type": "compass", "angle": 225, "maxDeg": 45, "prompt": "…" }                                          // เข็มทิศล้วน
{ "type": "compass", "from": {"lat":…,"lng":…,"name":"A"}, "to": {"lat":…,"lng":…,"name":"B"} }          // ประกอบแผนที่ (คำนวณมุมให้เอง)
```
- `seconds` เวลาของข้อนั้น · `maxKm` ระยะที่ได้ 0% · `labels:false` ซ่อนชื่อสถานที่ · `grid` ระยะเส้นกริด (ลิปดา) · `readout` = none | dec | dms · `hint` คำใบ้ · `say` ข้อความที่ให้เสียงพูดอ่าน (ไม่ใส่ = อ่านโจทย์)
- ตัวแปรบนสุด: `countdownSeconds`, `revealSeconds`, `questionSeconds` (ค่าเริ่มต้นเมื่อข้อไม่ระบุ)
- ระหว่างแก้หน้าเว็บ ใช้ `DEV=1 node server.js` เพื่ออ่านไฟล์สดทุกครั้ง

## ซ้อมก่อนสอนจริง

จำลองนักเรียน 90 คนเข้าเล่น (เปิดอีกหน้าต่าง Terminal):

```bash
node simulate.js 90
```

## ข้อควรระวัง

- **ต้องมีอินเทอร์เน็ต** บนมือถือนักเรียน เพื่อโหลดแผนที่ (OpenFreeMap) — หน้าเกมโหลดจากคอมครูโดยตรง
- ถ้าไม่พบ `cloudflared` หรืออุโมงค์สร้างไม่สำเร็จ QR จะกลับไปเป็นลิงก์ Wi-Fi วงเดียวกัน (จอจะขึ้นเตือนสีแดง)
- ปิดอุโมงค์เพื่อใช้เฉพาะ Wi-Fi วงเดียวกัน: `TUNNEL=off node server.js` / ใช้ลิงก์ของตัวเอง (โดเมน/เซิร์ฟเวอร์ภายนอก): `PUBLIC_URL=https://... node server.js`
- รันเซิร์ฟเวอร์ครูเปิดไว้ตลอดเกม ปิดหน้าต่างเมื่อไหร่ ลิงก์สาธารณะจะหยุดทำงานทันที
- หน้าจอครู (`/host`) เปิดได้เฉพาะบนเครื่องที่รันเซิร์ฟเวอร์ นักเรียนเข้าไม่ได้
- นักเรียนหลุดแล้วเปิดลิงก์ใหม่ → กลับเข้าเกมเดิมอัตโนมัติ (จำชื่อไว้ในเครื่อง)
